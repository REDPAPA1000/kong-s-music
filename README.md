# 연정쌤의 음악 교실

초등 1·2학년 합반부터 고등학교 1학년까지, 가창·기악·감상·창작 수업 자료를 한곳에서 여는 정적 웹사이트 프로토타입입니다.

## 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 다음 명령을 실행합니다.

```powershell
python -m http.server 8796
```

브라우저에서 `http://localhost:8796`을 엽니다. 파일을 직접 더블클릭해도 기본 화면은 보이지만, PDF 미리보기는 로컬 서버에서 실행할 때 가장 안정적입니다. 다른 프로그램이 8796 포트를 사용 중이면 사용하지 않는 포트 번호로 바꿔도 됩니다.

## 자료 추가

1. PDF를 `assets` 폴더에 넣습니다.
2. `app.js`의 `resources` 배열에 학년, 영역, 제목, PDF 주소, 영상 주소, 수업 흐름을 추가합니다.
3. QR이 비바샘 스마트 악보로 연결되면 `mediaUrl`에 등록하고, 스마트 수업안은 `guideUrl`, 해당 쪽으로 열리는 교과서 주소는 `ibookUrl`에 넣습니다. 주소가 확정되지 않았다면 해당 값을 빈 문자열로 둡니다.

## 다음에 필요한 실제 자료

- 공개 사용이 가능한 선생님 사진
- 선생님 소개글과 사이트 이름
- 나머지 QR의 공식 스마트 PPT 연결 주소와 이용 권한
- 비바샘 이외 자료의 영상 제공 방식
- 공개 사이트인지 교사용 비공개 사이트인지에 대한 결정
